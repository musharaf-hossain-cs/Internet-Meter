# Version history

This file maps each Internet Meter release to the changes included in that version.

## 1.0.3 - 2026-10-25

- Replaced the duplicate-instance information dialog with activation of the already-running Internet Meter window.
- Made the Windows taskbar deskband background visually transparent so only the download and upload speed text is drawn over the taskbar.
- Fixed SHA-256 manifest generation when packaging with Windows PowerShell 5.1.

## 1.0.2 - 2026-10-25

- Added the Internet Meter application icon and complete branding asset set.
- Applied the branding to the executable, installer, tray icon, and dashboard header.
- Updated the README dashboard images to show the branded application and populated traffic graph.

## 1.0.1 - 2026-10-25

- Initial public release.
- Added the Windows 10 native taskbar deskband, WPF dashboard, notification-area controls, and single-instance protection.
- Added live network monitoring, traffic graphs, per-application traffic, usage history, CSV export, alerts, stopwatch, adapter selection, and connection inspection.
